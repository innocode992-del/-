# حفظني - نسخة المساعد المحلي بدون API

هذه النسخة تستخدم المساعد الخفيف الموجود داخل ملف HTML الأصلي.

- لا تحتاج مفتاح Gemini أو OpenAI.
- لا تحتاج Environment Variables في Vercel.
- لا تحتاج مجلد api أو دوال Serverless للمساعد.
- المساعد يعالج الأسئلة محليًا باستخدام JavaScript وقاعدة معرفة وقواعد مخصصة محفوظة في المتصفح.

ملاحظة: هذا محرك محلي خفيف وليس نموذج محادثة توليدي مثل Gemini أو ChatGPT؛ لذلك نطاق إجاباته يعتمد على المعرفة والقواعد الموجودة داخله.

## النشر على Vercel مع GitHub
ارفع `index.html` إلى جذر المستودع. لا تضف ملفات `api` الخاصة بربط Gemini لهذه النسخة، واحذف أو أزل ربطها من المشروع إذا لم تعد تريد Gemini.
