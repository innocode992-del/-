حفظني - AI ياسين بن محمد (نسخة الشخصية والفهم)

محتويات الحزمة:
- index.html: واجهة البرنامج. يتضمن إصلاح متغير searchNotice الذي كان قد يسبب خطأ بعد رد ناجح من Gemini.
- api/ai.js: خادم Vercel الذي يتصل بـ Gemini، ويحتوي تعليمات شخصية AI ياسين بن محمد باللهجة المصرية، وفهم السياق، والتعامل مع الاسم، والبرمجة، والمعرفة العامة والدينية، والبحث عند الحاجة.

الرفع:
1) استبدل index.html في جذر GitHub بهذه النسخة.
2) داخل مجلد api الموجود بالفعل، استبدل ai.js بهذه النسخة. لا تنشئ مجلد api ثانيًا.
3) تأكد من المسارات:
   /index.html
   /api/ai.js
4) اعمل Commit changes وانتظر Vercel حتى يظهر Deployment بحالة Ready.

Vercel:
- اترك GEMINI_API_KEY كما هو في Environment Variables لمشروع psi-three-23.
- لا تضع المفتاح في أي ملف أو داخل GitHub.
- لا تحتاج إلى متغير جديد.

السلوك:
- اسم المساعد AI ياسين بن محمد.
- يتحدث باللهجة المصرية الطبيعية للمستخدم العربي، وباللغة التي يختارها المستخدم للغات الأخرى.
- يراعي الاسم وسجل آخر المحادثة والقواعد المخصصة التي يرسلها الواجهة.
- لا يطلب إعادة صياغة سؤال واضح ولا يرد بطلب سياق لمجرد قصر الرسالة.
- يوازن بين إجابات قصيرة مباشرة وتفصيل للأسئلة المعقدة.
- يستخدم التفكير المتوسط للأسئلة اليومية والعالي للأسئلة المركبة، دون عرض سلسلة التفكير الداخلية.
- يستخدم Google Search عند الحاجة إذا كانت الميزة متاحة لمفتاح Google AI Studio.
- في الأمور الدينية لا يخترع آيات أو أحاديث أو أحكامًا، ويصرح بعدم التأكد عند غياب التحقق.

ملاحظة:
- هذه النسخة تحتاج اتصالًا حيًا بـ Gemini عبر Vercel؛ من دون GEMINI_API_KEY أو مع تجاوز حصة الاستخدام لن يمكن للنموذج الرد.
- Google Search قد يخضع للتوفر والحصة والفوترة بحسب حساب Google AI Studio.
