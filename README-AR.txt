طريقة إضافة AI إلى مشروع حفظني على GitHub وVercel

محتويات الحزمة:
- index.html: نسخة من صفحة حفظني الحالية، مضاف إليها تبويب AI وواجهة المحادثة.
- api/ai.js: دالة Vercel الخلفية التي تتصل بـ Gemini وتحافظ على سرية المفتاح.

خطوات الرفع:
1) افتح مستودع GitHub الخاص بمشروع حفظني.
2) استبدل ملف index.html الموجود في جذر المستودع بملف index.html الموجود هنا.
3) أنشئ مجلدًا اسمه api في جذر المستودع (بجوار index.html).
4) داخل api أنشئ ملفًا اسمه ai.js، وانسخ إليه محتوى api/ai.js الموجود هنا.
5) احفظ التغييرات وارفعها إلى GitHub. إذا كان Vercel مربوطًا بالمستودع فسيبدأ نشر جديد تلقائيًا.

إضافة المفتاح السري (لا تضع المفتاح داخل HTML أو GitHub):
1) افتح مشروعك في Vercel.
2) Settings > Environment Variables.
3) أضف متغيرًا باسم GEMINI_API_KEY.
4) الصق قيمة المفتاح من Google AI Studio، واختر النوع Secret، وفعّله على Production (وPreview إذا أردت التجربة هناك).
5) اضغط Save ثم أعد نشر آخر Deployment حتى يقرأ المفتاح الجديد.

ملاحظة مهمة:
- واجهة AI تستدعي المسار /api/ai، لذلك تعمل بعد نشرها على Vercel، وليس عند فتح index.html بالنقر المزدوج من الكمبيوتر (file://).
- لا تشارك GEMINI_API_KEY ولا تضعه في index.html أو مستودع GitHub.
- توجد حدود مبسطة لطول الرسائل وعدد الطلبات لكل نسخة تشغيل. قبل مشاركة الموقع على نطاق واسع، فعّل Vercel Firewall أو وسيلة تحديد معدل طلبات على /api/ai.
